## 🇺🇸 English

A collection of courses and hands-on projects documenting my growth as a QA engineer. Each submodule is a self-contained repository with its own code, tests, and documentation.

### 📚 Courses

#### 🎭 [Playwright JS/TS — From Scratch to Framework](https://github.com/MizAndhre/playwright-js-ts-from-scratch-framework)

> Rahul Shetty Academy · Udemy

Complete Playwright learning environment covering UI automation, API testing, and professional framework architecture. Built against the **EventHub** application.

| Topic | What's covered |
|-------|---------------|
| UI Basics | CSS/XPath selectors, modern locators, calendars, frames, visual testing |
| API Testing | REST requests, session management, network interception, mocking |
| Page Object Model | Scalable architecture with POM, DDT, and fixtures — in JS and TypeScript |
| BDD / Cucumber | Executable specs with `.feature` files and step definitions |
| Excel Testing | Download → Modify → Upload → Validate cycle using ExcelJs |
| Playwright Agents | AI-assisted test generation with GitHub Copilot agents (TodoMVC) |
| Reporting | Allure dashboard and native Playwright HTML reporter |

---

#### 🔌 [API Testing with Playwright & TypeScript](https://github.com/MizAndhre/api-testing-playwright-ts)

> Bondar Academy · Udemy

Professional API testing framework built from scratch against the **Conduit API**. Focuses on reusable patterns and framework design.

| Topic | What's covered |
|-------|---------------|
| API Basics | GET, POST, PUT, DELETE with Playwright's request context |
| Fluent Request Builder | Chainable `RequestHandler` for readable, reusable HTTP calls |
| Fixtures & Auth | Worker-scoped JWT token injection — generated once, reused across tests |
| Custom Matchers | Domain-specific assertions with automatic API log attachment on failure |
| Schema Validation | Auto-generate and validate JSON schemas using AJV |
| Structured Logging | Full request/response logging via `APILogger` |
| Data Generation | Realistic test data with Faker.js |
| Data-Driven Testing | Parametrized tests across multiple datasets |
